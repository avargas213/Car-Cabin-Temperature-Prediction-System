# Python Data Logger

## Overview

The Python data logger communicates with the ESP32 over a 115200-baud serial connection and records data generated during prediction tests.

It stores raw temperature measurements, initial prediction values, adaptive correction updates, and final prediction error. The logger is designed to support the 30-second, 45-second, and 60-second prediction models used by the Car Cabin Temperature Prediction System.

## Features

- Connects to the ESP32 over serial communication
- Records temperature samples during each test
- Stores data for 30 s, 45 s, and 60 s prediction windows
- Records initial prediction values generated by the ESP32
- Records adaptive prediction updates
- Calculates prediction change relative to the initial prediction
- Calculates initial and final prediction error
- Automatically assigns test numbers based on existing saved data
- Saves results in CSV format
- Exits after a completed test is saved

## Serial Communication

The logger listens for several message types sent by the ESP32.

### Start of Test

```text
NEW PREDICTION TEST START
```

This initializes a new experiment and assigns the next available test number.

### Temperature Sample

```text
SAMPLE,experiment_time,temperature
```

Example:

```text
SAMPLE,21.52,84.31
```

Temperature samples are stored as the raw experimental data used by the prediction models.

### Initial Prediction

```text
INITIAL_MODEL,experiment_time,temperature,model_time,prediction
```

Example:

```text
INITIAL_MODEL,30.02,90.14,30,142.6
```

The initial prediction is stored in memory and associated with its corresponding prediction window.

The logger currently supports:

```python
MODEL_TIMES = [30, 45, 60]
```

### Adaptive Correction

```text
CORRECTION_UPDATE,experiment_time,temperature,model_time,corrected_prediction
```

Example:

```text
CORRECTION_UPDATE,50.04,96.21,30,135.8
```

Each adaptive update is saved along with the initial prediction and the percentage change between the two predictions.

### Test Completion

```text
ACTUAL_TIME_SECONDS: value
```

When the actual completion time is received, the logger calculates the initial and final prediction errors and saves the final test result.

---

## Data Logging Process

The logger follows this general sequence:

1. Connect to the ESP32.
2. Wait for a new prediction test to begin.
3. Assign the next available test number.
4. Record incoming temperature samples.
5. Store initial predictions for the 30 s, 45 s, and 60 s models.
6. Record adaptive prediction updates.
7. Receive the actual completion time from the ESP32.
8. Calculate prediction errors.
9. Save the final results.
10. Close the serial connection and exit.

---

## Output Files

The logger generates two types of CSV files for each prediction window.

### Initial Model Files

```text
Initial_Model_30s.csv
Initial_Model_45s.csv
Initial_Model_60s.csv
```

These files contain the raw temperature measurements collected during the experiment.

Columns:

```text
Test Number
Sample Number
Experiment Time Seconds
Test Time Seconds
Temperature F
```

The same underlying temperature experiment is written to each prediction-window file so the 30 s, 45 s, and 60 s models can be evaluated using consistent test data.

### Correction Files

```text
Correction_30s.csv
Correction_45s.csv
Correction_60s.csv
```

These files contain the adaptive prediction results.

Columns:

```text
Test Number
Experiment Time Seconds
Temperature F
Initial Prediction Seconds
Corrected Prediction Seconds
Prediction Change Percent
Actual Time Seconds
Initial Error Percent
Final Error Percent
```

During the experiment, adaptive correction rows contain the current corrected prediction. Once the test is complete, a final row records the actual completion time and prediction errors.

## Prediction Error

Prediction error is calculated relative to the actual time required for the cabin to reach the target temperature.

```python
def percent_error(prediction, actual):
    if prediction is None or actual is None:
        return ""

    if actual == 0:
        return ""

    return round(
        abs(prediction - actual)
        / actual
        * 100,
        2
    )
```

This allows the initial prediction and the final adaptive prediction to be compared directly.

---

## Prediction Change

The logger also records how much the adaptive prediction changes relative to the original prediction.

```python
def prediction_change_percent(
    initial_prediction,
    corrected_prediction
):
    if (
        initial_prediction is None
        or corrected_prediction is None
    ):
        return ""

    if initial_prediction == 0:
        return ""

    return round(
        abs(
            corrected_prediction
            - initial_prediction
        )
        / initial_prediction
        * 100,
        2
    )
```

This provides a way to measure how strongly the adaptive model adjusts the original prediction during a test.

---

## Adaptive Update Handling

When a correction update is received, the most recent corrected prediction is stored for the corresponding prediction window.

```python
last_corrected_predictions[
    model_time
] = corrected_prediction

change_percent = (
    prediction_change_percent(
        initial_prediction,
        corrected_prediction
    )
)
```

This value is later used as the final corrected prediction when the experiment ends.

---

## Final Test Result

When the ESP32 reports the actual completion time, the logger calculates both the initial and corrected prediction errors.

```python
initial_error = (
    percent_error(
        initial_prediction,
        actual_time
    )
)

final_error = (
    percent_error(
        corrected_prediction,
        actual_time
    )
)
```

If no adaptive correction was received for a model, the initial prediction is used as the final prediction.

## Local Configuration

The logger optionally reads a machine-specific output path from:

```text
local_config_logger.py
```

Example:

```python
DATA_FOLDER = r"C:\path\to\your\test\data"
```

`local_config_logger.py` is excluded from Git. If the file is not present, the logger defaults to the repository-level `Saved Data/` folder.

---

## Requirements

The logger requires Python and the `pyserial` package.

Install the required package with:

```bash
pip install pyserial
```

The ESP32 serial baud rate is currently:

```python
BAUD = 115200
```

The serial port may need to be changed depending on the computer being used.

---

## Running the Logger

Run the logger from a terminal with:

```bash
python logger.py
```

The logger will wait for the ESP32 connection and begin recording once it receives:

```text
NEW PREDICTION TEST START
```

After the ESP32 reports the actual completion time, the test data is saved and the logger exits.
