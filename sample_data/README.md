# Sample Data

This folder contains a representative subset of vehicle testing data from Version 5.2 of the Car Cabin Temperature Prediction System.

## Files

- `v5.2_vehicle_test_conditions.xlsx`  
  Records the environmental and vehicle conditions for each test, including starting cabin temperature, outside conditions, HVAC settings, and actual completion time.

- `v5.2_initial_model_45s.xlsx`  
  Contains the temperature samples collected during the 45-second initial prediction model.

- `v5.2_adaptive_correction_45s.xlsx`  
  Contains the adaptive prediction updates produced after the initial prediction, including corrected predictions and final prediction error.

These files are included as representative examples of the testing and validation process. The full experimental dataset is not included in the public repository.
